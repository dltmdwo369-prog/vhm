  - 2026-11-07 사용자가 잠금 암호를 만듦. 같은 창에서 두 번째 잠금 창의 '열기' 버튼이 눌린 채 남던 버그 수정, 생체인증 등록은 잠금을 푼 뒤 버튼을 한 번 더 누르는 방식
- **상담 메모 (2026-11-08 추가)**: 매일 묻는 항목을 체크·입력하면 메모 문장이 자동으로 만들어지고 '복사하기'로 기관 전용앱 메모란에 붙여 넣음. 태블릿·휴대폰 브라우저에서도 사용(로그인 없이도 열림)
  - 체크·입력 내용과 만들어진 문장은 저장·전송 안 함(건강정보). 탭을 닫거나 '다음 대상자'를 누르면 사라짐
  - 질문 항목·문장 틀만 저장: 이 기기 + 드라이브가 연결되어 있으면 드라이브 `방문건강관리 연계자료/vhm-notes.json`(기기 간 공유)
  - 방식: 하나 고르기 / 여러 개 고르기(문장 틀 `{선택} 교육함.`) / 숫자 입력(문장 틀 `혈압 {1}/{2}mmHg 측정함.`). 문장 사이 띄어쓰기·줄바꿈 선택
  - **Vital 형식 (사용자 지정 2026-11-08)**: `*Vital` 다음 줄에 `-BP: 120/60mmHg, PR: 80회/분, BST(공복): 120mg/dL`. 안 적은 수치 조각은 빠지고, 공복/식후를 안 고르면 `BST: …`. 그 뒤 문장은 다음 줄부터
  - 수치 옆 정상·주의·높음·낮음 표시(참고용). 기본 기준: 대한고혈압학회 2022(수축기 정상 ~119·주의 ~139·≥140 높음·<90 낮음, 이완기 ~79·~89·<60), 대한당뇨병학회(공복 ~99·주의 ~125, 식후 2시간 ~139·주의 ~199, <70 낮음), 맥박 60~100. 항목 편집에서 기준 수정 가능. '메모에도 ↑↓ 표시' 선택 가능(기본 끔)
  - **급성질환 (2026-11-09)**: 만성질환 다음 '급성질환'(감기·독감·코로나19·폐렴·기관지염·요로감염·장염·대상포진·골절·염좌·피부질환·결막염). 한 번 누르면 치료중, 두 번 완치, 세 번 해제 → `*주질환` 줄에 만성질환 뒤로 `-고혈압, 폐렴(치료중), 대상포진(완치)`
  - **문장 앞 - (2026-11-09)**: 컨디션·수면 등 하나/여러 개 고르기·숫자 문장 앞에 `-`를 붙여 한 줄씩. 항목 편집의 '문장 앞에 - 붙이기'로 끌 수 있음
  - **서두 (2026-11-09)**: 맨 위 '서두' — 입력칸(예: 신규등록을 위해) + 방문함/내소함/동행방문함 → 메모 첫 줄 `*신규등록을 위해 방문함.` (앞에 * — 사용자 요청, 항목 편집에서 바꿀 수 있음. 입력 없으면 `*방문함.`). 입력 문장은 저장 안 함
  - **직접 고치기 (2026-11-09)**: 만들어진 메모를 직접 고쳐도, 버튼·숫자를 바꾸면 바뀐 문장만 그 자리에 반영(고친 부분 유지). '다시 만들기' 버튼 없음. 자리를 못 찾으면 맨 아래에 붙이고 알림
  - **만성질환 (2026-11-09)**: 건강 상태 맨 앞 '만성질환'(여러 개 고르기: 고혈압·당뇨병·이상지질혈증·관절염·척추질환·골다공증·뇌졸중·심장질환·치매·암·만성폐질환·만성콩팥병·갑상선질환·전립선비대증·우울증) → 메모 `*주질환` / `-고혈압, 당뇨병`
  - **당화혈색소 (2026-11-09)**: 측정 > Vital 다음. 메모 `-HbA1c: 6.5%`(Vital 묶음 아래 줄로 붙음). 판정: 대한당뇨병학회 진단기준 — 5.7 미만 정상, 5.7~6.4 주의(당뇨병 전단계), 6.5 이상 높음. '-'·'*'로 시작하는 줄은 항상 따로 한 줄
  - **신체계측 (2026-11-10, 커밋 01bfd1d)**: 측정의 '체중' 항목을 '신체계측'으로 바꿈(틀 schema 12, 예전 틀은 체중 자리에 자동 교체). 키(cm)·몸무게(kg) 입력 → BMI 자동 계산(소수 첫째 자리, 직접 입력 칸 아님). 메모 `*신체계측` / `-키: 160cm / 몸무게: 55kg / BMI: 21.5` (빈 칸은 ' / ' 단위로 빠짐). 판정: 대한비만학회 2022 — 18.5 미만 저체중, 18.5~22.9 정상, 23~24.9 비만 전단계, 25~29.9/30~34.9/35 이상 1·2·3단계 비만
  - **상담기록 순서 재배치 (2026-11-10, 틀 schema 13)**: 사용자 기록 순서대로 묶음 = 메모 머리줄. 상담목적(머리줄 없음: *서두 + -상담 내용) → *Vital(BP·PR·BST, HbA1c) → *주질환(만성+급성) → *복약(-복용약: …, 복약 순응, 투약 중단, -영양제: …) → *신체계측 및 신체사정(키·몸무게·BMI, 눈·귀·구강건강, 관절, 악력) → *건강상담(컨디션·통증·수면·식사·배변·기분·정서·낙상·건강검진·교육 내용) → *생활습관(흡연·음주·신체활동) → *서비스제공(-물품: …, -보건복지서비스 연계: … — 직접 적기 + 빠른 입력 보기) → *기타사항(마무리 + 직접 적기). 묶음 사이 빈 줄
