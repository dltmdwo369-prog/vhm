# 일정 메모의 이미지 첨부

업무 일정과 개인일정·메모의 등록/수정 창에서 **이미지 선택**을 누릅니다. JPG/PNG/GIF/WEBP를 파일당 5MB, 일정당 3개까지 선택할 수 있습니다. 이미지 파일만으로도 개인 메모를 저장할 수 있습니다.

이미지를 처음 저장하려면 기존의 Google Drive 연결과 메모 잠금 암호가 필요합니다. Drive 연결은 기존 `drive.file` 권한을 사용하며 새 권한을 추가하지 않습니다. 현재 로그인 방식은 Google로 이동했다 돌아오기 때문에 연결 버튼에 작성 내용 초기화를 명시했습니다. 내용을 먼저 저장한 뒤 연결하세요. 선택한 파일과 미저장 내용은 복구용 저장소에 자동 보관하지 않습니다.

선택은 브라우저 메모리에만 유지되고 **일정 저장** 시 파일명과 이미지 바이트를 기존 메모의 AES-GCM 키로 암호화한 뒤 개인 Drive에 업로드합니다. Drive에는 무작위 파일명과 암호문만 전달하고 공유 권한을 추가하지 않습니다. Calendar에는 파일 ID 목록만 비공개 확장 속성 `vhm_images`로 보관하며, 설명·일정 제목·Google Calendar 첨부파일에는 원본을 넣지 않습니다. Google Calendar 앱에서 이미지를 보려면 이 웹사이트를 이용해야 합니다.

저장된 일정의 메모란에서 **보기**를 누르고 잠금을 풀면 미리보기와 원본 다운로드가 가능합니다. 이미지와 원래 파일명은 화면 메모리에서만 복호화되며 잠금·로그아웃·창 닫기 때 미리보기 URL을 해제합니다. 메모 잠금 암호를 잊으면 첨부 이미지도 복구할 수 없습니다.

**첨부 해제** 후 일정을 저장하면 해당 일정과의 연결만 제거합니다. 취소는 저장된 연결을 바꾸지 않습니다. 일정 삭제·첨부 해제는 Drive 원본을 자동 삭제하지 않으므로 일정 복원과 다른 연결을 보호합니다. 업로드 후 일정 저장에 실패하면 재시도 시 이미 업로드한 파일 ID를 재사용합니다. 그 상태에서 취소하거나 업로드 도중 창을 닫으면 연결되지 않은 암호화 파일이 Drive에 남을 수 있습니다.

일정 JSON 백업에는 이미지 연결 정보만 포함되며 실제 이미지 파일은 포함되지 않습니다. 복원한 계정에서 해당 Drive 파일에 접근할 수 있어야 하며, 원본 암호화 키도 필요합니다. 다른 계정으로 이미지 접근 권한이나 암호를 자동 이전하지 않습니다. 손상된 첨부 목록은 오류를 표시하고 원문을 보존합니다. 다른 기기의 일정 수정은 기존 ETag 충돌 처리에 따르며 덮어쓰기를 자동 강제하지 않습니다.

개발·자동 테스트에는 가상 계정, 가짜 Google 응답과 생성된 1픽셀 이미지만 사용합니다. 실제 대상자 자료는 사용하지 않습니다.
