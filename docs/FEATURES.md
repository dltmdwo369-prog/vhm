# 사용할 기능 설정

설정 → ‘사용할 기능’에서 일정, 상담 메모, 연계 안내, 보관함, 교육자료, 피드백을 토글 스위치로 켜고 끕니다. 처음에는 모두 켜져 있습니다. 끈 기능은 메뉴에서 숨겨지며 직접 탭 전환 요청이 와도 활성화된 기능으로 이동합니다. 모두 끄면 설정 화면을 표시합니다. 설정과 관리자 전용 피드백 관리는 항상 접근할 수 있습니다.

이 설정은 **현재 브라우저에서 Google 계정별로** 저장됩니다. 로그인 전 설정은 별도로 보관합니다. 다른 기기·브라우저로 동기화하지 않습니다. 연결된 계정은 기존 Calendar 부트스트랩의 주 계정 이메일로 구분합니다. 로그인·로그아웃 시 해당 계정·로그인 전 설정으로 전환합니다.

기능을 끄는 것은 화면 기능을 숨기는 동작입니다. Google Calendar·Drive 자료, 상담 메모 틀, 작성 중인 메모 및 기존 피드백을 삭제하거나 Google 권한을 철회하지 않습니다. 일정 기능을 꺼도 설정의 ‘구글 계정으로 연결’로 연결·재연결할 수 있습니다. 일정 기능이 꺼져 있으면 연계 안내의 ‘연계 일정 등록’은 설정에서 일정 기능을 켜도록 안내합니다.

`src/features.js`가 표시·저장을 담당하고 `showTab`에서 비활성 탭 진입을 막습니다. 로컬 저장이 실패하면 스위치를 원래 상태로 되돌리고 저장 실패를 알립니다. `node tests/test-features.js`로 가상 계정 분리, 전체 끄기·복구, 키보드 조작, 재접속, 데이터 보존 및 저장 실패를 검사합니다.
