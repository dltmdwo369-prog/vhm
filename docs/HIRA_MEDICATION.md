# 심평원 ‘내가 먹는 약 한눈에’ 상담 연결 (2026-11-17)

상담메모 상단의 **심평원에서 본인인증·조회**와 처방약 입력 옆 **심평원 복약정보 확인**은 사용자가 제공한 공식 주소를 새 창으로 엽니다.

https://www.hira.or.kr/rb/dur/form.do?pgmid=HIRAA050300000100

**대상자 휴대폰으로 열기**를 펼치면 QR과 주소 복사, 이용 순서가 보입니다. 대상자 본인이 휴대폰 카메라로 QR을 읽고 공식 화면에서 본인확인정보·인증번호를 입력합니다. 이후 대상자가 보여주는 화면을 함께 확인하며 상담합니다. 조회를 마친 뒤에는 공식 서비스에서 로그아웃하고 화면을 종료하도록 안내합니다.

이 기능은 공식 사이트로 안내하는 연결 기능입니다. 우리 사이트 안에 심평원 인증창을 복제하거나 SMS를 발송하지 않으며 조회 결과를 읽어오거나 수집·저장하지 않습니다. 대상자의 이름·전화번호·주민등록번호·인증번호 입력란을 추가하지 않았습니다. 기존 상담 약 목록에 사용자가 직접 작성하는 기능과 명시적 상담 저장은 기존대로 유지됩니다.

공식 인증 방식, 휴대폰 문자 인증 제공 여부, 이용 가능한 조회 항목·기간, 외부 API 제공·이용 자격은 이번 작업에서 확인하지 못했습니다. 실행 환경에서 공식 URL 요청이 프록시의 HTTP 403으로 차단되어 실제 화면과 인증 흐름을 열지 못했습니다. 문자 인증이 지원된다고 확정 표시하지 않으며 심평원이 실제 제공하는 절차를 따르도록 안내합니다. 외부 인증 API를 통한 사이트 내부 연동을 배포한 것으로 보아서는 안 됩니다.

링크는 고정 공식 주소만 사용하며 개인정보나 상담 내용·조회 식별자를 URL에 추가하지 않습니다. 새 창은 `noopener noreferrer`와 `no-referrer`로 열어 원래 창과 참조 주소 전달을 차단합니다. iframe·인증 프록시·스크래핑·새 서버·추적 스크립트는 추가하지 않습니다. 클릭 전에는 심평원 서버에 접속하지 않습니다.

QR은 `assets/hira-medication-qr.svg`에 정적 원본으로 관리하고 빌드 때 `site/assets/`에 복사합니다. 외부 QR 서비스 없이 qrcode 8.2로 공식 주소만 인코딩했습니다. URL이 바뀌면 `src/notes.js` 상수와 QR을 함께 변경해야 합니다. 실행·빌드에 qrcode 패키지는 필요하지 않습니다.

검증: 기존 상담메모 테스트 52개와 기존 화면 반응형 4종 통과. 별도 로컬 브라우저에서 1440·768·390·320px의 펼친 QR 안내, 이미지 로드·주소 복사·안전한 새 창·개인정보 매개변수 및 Referrer 부재·자동 외부 요청 부재·현재 메모 보존을 확인했습니다. 렌더링된 QR을 ZXing으로 독립 디코딩하여 공식 URL과 일치함을 확인했습니다. 외부 창은 가짜 응답으로 시험했으며 실제 심평원 인증·SMS·휴대폰 카메라 스캔·복약정보 조회는 실행하지 않았습니다. 전체 401개 회귀 및 Firestore 에뮬레이터는 이번 링크/UI 수정 범위에서는 재실행하지 않았습니다.
