# 상담 메모 체크 → 연계 안내 자동 연결

## 사용 방법

상담 메모에서 필요한 항목을 체크한 뒤 **체크 항목으로 연계 보기**를 누른다. 상담 메모에서 상단 **연계 안내** 탭으로 직접 이동해도 동일하게 적용한다. 관련 요구가 자동 체크되고 ‘요구 체크 → 추천’의 검토 후보가 즉시 표시된다. 상담에서 가져온 항목이 있는 분야는 자동으로 펼친다. 자동 연결 후 검토 후보 영역으로 이동해 모바일에서도 결과를 바로 볼 수 있고, ‘검토 후보 보기’ 버튼으로 다시 이동할 수 있다.

연계 안내에서 체크를 직접 추가·해제할 수 있다. **상담 메모 체크 다시 적용**을 누르면 현재 상담 체크를 다시 반영한다. 수동으로 추가한 요구는 재적용 시 보존하며, 더 이상 상담에서 선택되지 않은 자동 요구는 제거한다. 자동 체크는 진단이나 지원 자격 판정이 아니므로 담당자가 실제 필요와 조건을 확인한다. 연결되지 않는 항목은 직접 요구를 선택한다.

새 대상자를 상담할 때 상담 메모의 **다음 대상자 (모두 지우기)**를 누른다. 상담 선택은 이름/대상자 ID와 연결해 보관하는 자료가 아니므로 프로그램이 새 대상자임을 추측하지 않는다.

연계 안내 기능을 설정에서 꺼두면 이동 버튼은 켜도록 안내하고 상담 화면을 유지한다. 로그인이나 Drive 권한 없이도 공개 카탈로그의 관련 후보를 볼 수 있다. 로그인 상태라면 기존 방식대로 개인 목록을 읽을 수 있지만, 상담 체크를 개인 목록 파일에 저장하지 않는다.

## 연결 기준

`src/note-referrals.js`에서 알려진 항목명·종류·실제로 선택된 보기 이름을 명시적으로 매핑한다. 저장된 질문 항목 ID는 사용자가 만든 임의 ID이므로 고정 ID를 가정하지 않는다. 다른 항목에서 같은 단어가 발견됐다는 이유로 추측하지 않는다.

|상담에서 선택한 항목|연계 요구 예시|
|---|---|
|고혈압·당뇨병·이상지질혈증 등 만성질환|혈압·혈당 등 건강관리 상담|
|관절염·척추질환·골다공증·뇌졸중 또는 관절 통증/기능 제한|보행·신체기능 재활 상담 (무릎 수술 자격으로 추정하지 않음)|
|치매|치매 등록·가족 돌봄 상담|
|암|암 치료비·의료사회복지 상담 (경제적 자격은 별도 확인)|
|약 가끔 거름·투약 중단 보기|복약 정리·건강상담 연결|
|백내장|백내장 등 안과 수술 지원 상담 (수술 적응증/지원 결정 아님)|
|시력저하·녹내장|시력 저하·안과 검사 상담|
|청력저하|난청·보청기 급여 상담|
|구강 불량 / 틀니 사용 / 저작 불편|구강검진 / 틀니 유지관리 / 저작 관련 상담|
|우울감·불안 / 식욕 저하·불규칙 식사 / 낙상 있음 / 잦은 음주|정서 / 영양 / 낙상 예방 / 정신건강 상담|
|급성 골절·염좌 ‘치료중’|재활 상담 (‘완치’이면 제외)|
|서비스 연계 빠른 입력 버튼으로 선택한 치매안심센터·장기요양 등급신청 등|기억력 검사 상담·장기요양 등 해당 요구|

‘양호·없음·안정·규칙적·완치’ 등을 문제 상태로 매핑하지 않는다. 기존 보청기를 쓴다는 사실만으로 새 지원이 필요하다고 추정하지 않는다. 일반적인 통증·수면·운동 부족 등 위치/목적이 불명확한 항목도 임의로 세부 지원사업에 연결하지 않는다. 같은 요구에 여러 상담 항목이 해당해도 요구는 한 번만 선택한다.

## 읽지 않는 정보

- 이름, 생년월일, 나이, 자유 입력한 상담 내용·추가 메모·수정한 결과 문장
- 처방약/영양제 이름·복용 메모
- 혈압·혈당·BMI·악력·Mini-Cog 등의 숫자와 결과
- 보기 설명 문장·고른 보기에 붙인 자유 입력 메모

숫자에서 새 진단·중증도·응급성·소득 자격을 계산하지 않는다. ‘긴급 지원 필요’는 상담 값으로 자동 선택하지 않는다. 서비스 연계 빠른 입력은 실제 버튼을 눌렀을 때만 별도 메모리로 추적하며, 그 입력칸을 직접 수정하면 해당 빠른 입력 추적은 지운다. 직접 적은 문장에서 기관명/질환을 검색하지 않는다.

## 데이터 흐름과 초기화

NOTES.referralNeeds()는 현재 체크로부터 정해진 요구 ID 배열만 반환한다. LINKS.open은 직전 메뉴가 상담 메모일 때 이를 받아 자동 요구와 수동 요구를 구분한다. 자동 요구를 다시 적용해도 사용자가 수동 추가한 요구는 유지한다. 이 흐름에는 네트워크 요청·분석 서버·저장소 기록·로그 출력을 추가하지 않았다. 상담 문장/이름을 URL·공유 문서·Drive·localStorage·sessionStorage에 쓰지 않는다.

연계 안내를 떠나면 기존 정책대로 해당 화면의 선택을 지운다. 상담 선택은 브라우저 메모리에 남아 있으므로 다음 상담 전에 초기화해야 한다. ‘다음 대상자’ 또는 기본 틀 초기화는 빠른 입력과 자동 연결 상태도 지운다. Google 연결 해제는 NOTES.resetSession으로 체크·문장·입력·연결 데이터를 모두 비우며 저장된 질문 틀은 삭제하지 않는다. 기존 OAuth 권한, Calendar/Drive 저장 프로토콜, 메모 암호화는 바꾸지 않았다.
