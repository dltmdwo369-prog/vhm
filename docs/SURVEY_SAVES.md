# 상담메모 기초조사표

메모쓰기 아래의 버튼에서 PHQ-9, SGDS-K, 허약노인 기초측정표,
재가암 대상자 기초조사표, 재가장애인 기초조사표(간이)를 작성한다.
문항은 forms-source/sheet1.html, sheet2.html과 forms/sgds-k-short-form.pdf에
따른다. 변형 바델 지수는 별도 검사이므로 이 5종에 포함하지 않는다.

대상자 식별 정보는 이름만 받는다. 저장 시각은 자동 기록한다.
미응답 상태로도 보관 가능하며 PHQ-9/SGDS-K는 응답한 문항 수와 점수를
표시한다. SGDS-K는 원본 별표 채점과 8점 이상 상담 권유 기준을 사용한다.
허약노인·암·장애인 조사표에는 검증되지 않은 자동 판정을 추가하지 않는다.

‘이 조사표 새로 저장’은 상담메모의 기존 저장 번호를 함께 사용한다.
수정 후 저장하면 기존 자료를 덮어쓰지 않고 새 번호로 추가한다.
이름과 응답은 조사표별로 저장하며 다른 상담 문장·약·필기는 넣지 않는다.
대상자 이름과 조사표 종류는 잠금 해제 후 저장 목록에서 확인한다.

기존 메모 잠금 암호, 암호화 IndexedDB 저장, 불변 Drive 저장 파일,
동기화 및 삭제 표식 처리 경로를 재사용한다. 입력 초안은 메모리에만 두고
저장 버튼을 눌렀을 때만 보관한다. 잠금·로그아웃·다음 대상자에서 초안을 지운다.

Drive 연결 후 ‘태블릿·컴퓨터 동기화’를 누르면 다른 기기와 주고받는다.
저장 동기화 설정이 켜져 있으면 연결된 Drive에도 저장한다.
기존 메모와 같은 계정 및 원래 잠금 암호를 사용해야 한다.
‘Drive에서도 삭제’는 온라인 Drive 연결 상태에서 확인 후 실행한다.
기기와 Drive 원본은 영구 삭제하고 휴지통에 넣지 않는다.
다른 기기의 원본 및 열어 둔 조사표는 다음 동기화에서 삭제 표식으로 정리한다.
삭제 표식은 무작위 ID와 암호 범위 식별값만 보관하며 이름과 응답은 포함하지 않는다.
오프라인이거나 Drive 삭제 확인에 실패하면 삭제 완료를 표시하지 않는다.

검증: test-surveys.js, test-consultation-delete.js (조사표를 대상으로 두 기기
동기화·삭제·재생성 차단 검증), 기존 consultation·sync·notes 테스트.
실제 개인 계정이나 실제 대상자 정보는 테스트에 사용하지 않는다.
