# 임시 보관함 — 구성과 사용 규칙 (2026-11-09 추가, 2026-11-10 사이트 탭으로 통합)

## 무엇인가
- 집·사무실·휴대폰 어디서든 같은 구글 계정으로 파일을 올리고 내려받는 임시 보관함. 업로드 후 **7일이 지나면 삭제**
- **2026-11-10: 메인 사이트(index.html)의 '보관함' 탭으로 통합**(커밋 2245cfa, 연계 안내 다음 탭). 사용자 요청 "내 웹사이트에 그대로 구현해줘"
  - 소스: `vhm-hosted/src/archive.js`(window.ARCHIVE) → build_site.py가 index.html에 넣음. CSS는 `ar-` 접두어로 사이트와 충돌 없게
  - 로그인은 사이트와 같은 페이지 이동 방식, 드라이브 권한은 연계 안내와 같은 drive.file. 권한이 없으면 '구글 드라이브 연결' → 돌아오면 보관함 탭
  - 같은 폴더·같은 클라이언트 ID·같은 만료 속성이라 archive.html에서 올린 파일도 탭에서 보이고, 반대도 같음
  - 올리기·내려받기 중에는 업무시간 연결 유지(조용한 재연결)가 기다림. 연결 해제 시 목록 비움
- 별도 주소 `https://dltmdwo369-prog.github.io/vhm/archive.html` 도 그대로 남아 있음(다른 대화 제작, 이 통합에서 수정 안 함)
- `archive-cleanup.gs`(선택: 서버측 자동 삭제용 Apps Script 예시, 실제 계정 미검증, 기본 DRY_RUN=true)

## 동작 방식
- 저장 위치: 본인 구글 드라이브 `방문건강관리 임시보관함` 폴더(앱이 만든 파일만 접근). 공유 설정 안 함(본인만)
- 만료: 파일 숨은 속성 `vhm_exp`(업로드 완료 시각+7일, ms). 속성 없으면 생성 시각+7일
- 자동 삭제: 탭을 열 때·새로고침·열려 있는 동안 1분마다 만료 파일을 영구 삭제(휴지통 거치지 않음, 올리기·내려받기 중엔 미룸). 만료 파일은 목록에서 숨기고 내려받기 차단. **사이트를 안 열면 삭제가 늦어질 수 있음** → 완전 자동은 archive-cleanup.gs(매일 트리거)로 보완 가능(선택)
- 업로드: 이어올리기(resumable) 8MB 단위, 실패 시 재시도·이어올리기, 진행률 표시. 올리기 전 '개인정보·건강정보 없음' 확인 체크 필수
- 내려받기: 크롬·엣지(컴퓨터)는 저장 위치를 골라 디스크로 바로 저장(스트리밍), 그 외(아이폰 사파리 등)는 메모리에 모았다가 저장 → 큰 파일은 컴퓨터에서 권장

## 용량
- 앱 설정 한도: **파일당 2GB**. 브라우저 내려받기 안정성 때문에 2GB로 제한
- 전체 용량은 본인 구글 저장공간(무료 15GB, 지메일·사진과 공유). 화면에 남은 용량 표시

## 개인정보·법 유의사항 (사용자 안내 완료)
