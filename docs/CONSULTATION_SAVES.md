# 상담메모 저장·손글씨·기기 간 동기화 (2026-11-17)

상담메모의 **새로 저장** 또는 입력란 아래 **상담메모 새로 저장**으로 체크·직접 고친 문장·코멘트·기타사항·질문 틀·손글씨를 저장1, 저장2…로 보관합니다. 매번 새 저장본을 만들어 기존 저장본을 덮어쓰지 않습니다.

## 세부항목 위치 배정 (2026-11-18)

만성질환·급성질환·교육 내용·물품·보건복지서비스 연계 옆의 **순서 변경**을 누릅니다. 같은 방식의 맞춤 복수 선택/빠른 입력 항목에도 제공됩니다. **↑↓** 또는 **순번** 선택으로 원하는 위치로 옮긴 뒤 **순서 저장**을 누르세요. **원래 순서**는 기존 옵션 배열의 순서로 되돌리고, 취소·닫기·Esc는 변경 중인 배치를 버립니다. ‘원래 순서’도 저장해야 적용됩니다. 항목 편집에서 바꾼 보기 이름·내용은 되돌리지 않습니다.

표시 순서만 별도 `optionOrder`에 저장하므로 기존 체크·치료중/완치·괄호 코멘트·빠른 입력·직접 고친 메모·연계 추천 연결은 유지됩니다. 메모의 문장 순서는 배치 변경만으로 바꾸지 않습니다. 사용자가 추가한 보기도 위치를 정할 수 있고, 항목 편집에서 보기 추가/삭제 시 남은 배치를 유지합니다.

배치는 기존 질문 틀과 함께 이 브라우저에 저장하며, Drive가 연결되어 있으면 기존 질문 틀 동기화 경로를 사용합니다. 체크한 대상자 정보나 상담 문장을 이 설정으로 저장/전송하지 않습니다. 다른 기기에서는 같은 Google 계정의 Drive를 연결해 상담메모 탭을 다시 열면 최신 질문 틀을 가져옵니다. 질문 틀 동기화는 기존 최신 수정시각 기준이며 서로 다른 기기에서 동시에 편집한 배치를 항목별 병합하지 않습니다.

저장1·저장2…를 열어 복원한 화면은 당시의 배치를 유지합니다. 그 화면에서는 순서 변경을 제한하며 **다음 대상자**로 전환하면 현재 개인 배치를 편집할 수 있습니다.

## 기존 태블릿 메모를 컴퓨터에서도 사용하기

1. **메모가 저장되어 있는 태블릿**에서 기존 사이트를 새로고침합니다. 같은 Google 계정으로 연결하고 기존 메모 잠금을 풉니다. 태블릿의 브라우저 데이터나 기존 저장본을 지우지 마세요.
2. Drive가 연결되어 있지 않으면 **Drive 연결**을 사용합니다. Google로 이동하면서 현재 작성 중인 화면은 초기화되므로 미저장 내용은 먼저 기기 저장하세요. 이미 기기에 저장한 메모는 유지됩니다.
3. **태블릿·컴퓨터 동기화**를 누릅니다. 태블릿의 기존 암호화 저장본을 Drive에 모두 복사하고 Drive의 다른 저장본도 가져옵니다. 성공·실패 건수를 확인하세요.
4. **컴퓨터**에서 같은 사이트·Google 계정으로 접속하고 Drive를 연결한 뒤 같은 원래 메모 잠금 암호로 엽니다. **저장한 메모 열기**, **저장 목록**, 또는 **태블릿·컴퓨터 동기화**로 자료를 불러옵니다.

태블릿에만 저장한 파일은 컴퓨터나 개발 환경에서 직접 읽을 수 없습니다. 처음 한 번은 반드시 태블릿에서 동기화를 실행해야 합니다. 현재 작업창·필기를 동기화만으로 덮어쓰지 않으며, 원하는 저장본을 선택해 열 때 내용을 복원합니다.

저장 번호는 각 기기에서 발급합니다. 다른 기기에서 새로 가져온 자료는 그 기기의 다음 번호를 받으므로 같은 메모라도 번호가 다를 수 있습니다. 내부 고유 ID로 같은 메모를 식별하고, 서로 다른 메모가 같은 표시 번호를 썼더라도 덮어쓰지 않습니다. 날짜·시간과 내용을 함께 확인하세요.

## 앞으로 저장할 때

- **저장할 때 Drive에도 동기화**는 기본으로 켜져 있습니다. 저장 버튼을 누르면 먼저 이 기기에 암호화 저장하고, 인터넷과 Drive 연결이 준비되어 있으면 해당 새 저장본도 Drive에 보관합니다. 저장 중인 입력을 매 타자마다 보내지는 않습니다.
- Drive 저장 성공 후 원격 파일의 암호문을 다시 읽어 기기 원본과 동일한지 확인합니다. 그 뒤에만 Drive 저장 완료 표시를 합니다. 확인된 원격 파일 ID·확인 시각을 기기 저장소의 부가 정보로 기록하며 기존 메모 암호문·ID·번호는 바꾸지 않습니다.
- 업로드 실패·연결 만료·오프라인이면 **기기 저장 완료 · Drive 동기화 대기**로 표시합니다. 기기 저장본을 유지합니다. 연결을 복구한 뒤 **태블릿·컴퓨터 동기화**를 누르면 대기 중인 과거 저장본도 함께 확인·전송합니다. 인터넷 복귀만으로 백그라운드 전송하는 기능은 추가하지 않았습니다.
- 동기화 설정을 끄면 새 저장은 기기에만 보관합니다. 사용자가 별도로 누르는 동기화/개별 Drive 복사는 계속 사용할 수 있습니다. 설정은 해당 브라우저에만 보관하며 상담 내용은 포함하지 않습니다.
- 저장 목록을 열 때 Drive가 연결되어 있으면 원격 저장본도 가져옵니다. 이 조회 동작은 기기의 미전송 자료를 자동으로 업로드하지 않습니다. 옛 태블릿 자료와 대기 자료를 한꺼번에 올리는 동작은 동기화 버튼으로 실행합니다.
- 번호별 **Drive에 복사**와 **Drive에서 불러오기**도 유지합니다.

## 손글씨와 복원

**손글씨 필기판 열기**에서 Apple Pencil·마우스로 작성합니다. 손바닥 오입력 방지를 위해 기본은 펜 전용이며, 손가락으로 그리려면 **손가락으로도 쓰기**를 켭니다. 색상·굵기·지우개·한 획 취소·전체 지우기를 제공합니다. [필기 수정·검증 범위](PENCIL_FIX.md)를 참고하세요.

**저장한 메모 열기 → 저장N**으로 문장·체크·코멘트·필기를 복원합니다. 당시 질문 틀을 화면에서 복원하되 현재 개인 질문 설정을 자동 변경하지 않습니다. 다음 대상자로 전환하면 현재 질문 틀로 돌아옵니다. 저장 메모의 질문 틀 편집은 제한합니다.

## 데이터 보호와 충돌 처리

- 기존 AES-GCM 키와 암호화 파일 형식 `vhm-consult1:`을 사용합니다. 로컬 IndexedDB `vhm-consultations-v1`에는 암호문·무작위 ID·시각·기기 번호·키 식별값·원격 파일 확인 정보만 보관하고, 본문·필기·잠금 암호는 평문으로 저장하지 않습니다.
- 같은 원래 키를 가진 계정/기기끼리 파일을 열 수 있습니다. 암호만 같고 Google 계정·원래 키가 다른 경우에는 복호화되지 않습니다. 잠금 암호를 잊으면 저장본도 복구할 수 없습니다.
- 잠금·로그아웃 때 현재의 복호화된 메모와 필기는 지웁니다. 암호화 저장본은 삭제하지 않습니다. 필요한 내용은 먼저 저장하세요.
- Drive는 기존 `drive.file` 권한과 기존 연계자료 폴더를 사용합니다. 무작위 이름의 암호화 파일만 보관하고 공유 권한을 추가하지 않습니다. 새 서버·분석 도구·OAuth 권한을 추가하지 않으며 `vhm-links.json`과 질문 틀 `vhm-notes.json`, 일정 자료를 덮어쓰지 않습니다.
- 동기화는 원격 자료를 검증하여 기기에 병합한 뒤 기기에만 남은 자료를 업로드합니다. 같은 ID·같은 암호문은 중복 추가하지 않습니다. 같은 ID의 다른 암호문이나 손상 파일은 덮어쓰지 않고 오류로 표시하며 기존 기기 원본을 유지합니다.
- 두 기기의 동시 저장은 별도 고유 ID로 보존합니다. 같은 파일을 동시에 Drive에 복사해 중복 파일이 생겨도 가져올 때 고유 ID로 합칩니다. 기기 번호는 IndexedDB 트랜잭션으로 배정해 같은 기기의 여러 탭에서도 덮어쓰지 않습니다. 삭제 번호는 재사용하지 않습니다.
- 동기화는 삭제를 전파하지 않습니다. **이 기기에서 삭제**해도 Drive 복사본은 남고 다음 불러오기/동기화 때 다시 표시될 수 있습니다. Drive에서만 삭제한 파일도 기기 원본이 남아 있으면 명시적 동기화 때 다시 올라갈 수 있습니다. 모든 사본 삭제를 원하면 사용자가 기기와 Drive의 해당 사본을 각각 관리해야 합니다.

## 외부·오프라인 사용과 제한

미리 사이트를 열고 로그인·잠금 해제를 마친 화면에서는 오프라인 기기 저장이 가능합니다. 처음 접속·로그인·암호 설정·Drive 연동에는 인터넷 연결이 필요합니다. 완전한 오프라인 앱 설치 기능은 추가하지 않았습니다.

기기 저장만 한 자료는 다른 기기에 나타나지 않으며, 브라우저 데이터 삭제·비공개 창 종료·기기 분실로 사라질 수 있습니다. 기존 일정 JSON 백업에는 상담 저장본이 포함되지 않습니다. 메모 한 건은 암호화 전 합계 2MB, 필기 2,000획·30,000점까지이고 Drive 불러오기는 한 번에 1,000파일까지입니다.

검증은 가짜 Google 응답과 별도 브라우저 기기의 가상 문장·필기로 수행합니다. 실제 사용자의 태블릿 저장소나 Google 계정에 접근하여 자료를 옮긴 것은 아닙니다.
