# 상담메모 저장·손글씨 (2026-11-17)

상담메모 상단의 **새로 저장**을 누르면 체크 항목, 직접 수정한 문장, 기타사항, 연계용 빠른 입력 선택, 질문 틀, 손글씨가 한 묶음으로 저장됩니다. 저장1, 저장2…로 번호를 붙이며, 다시 저장할 때마다 새 저장본을 만듭니다. 기존 저장본을 자동 덮어쓰지 않습니다.

## 사용 방법

1. Google 연결 및 메모 잠금 암호를 준비합니다. 메모 잠금은 일정 메모·이미지 첨부와 같은 암호를 사용합니다.
2. 상담 체크와 문장을 작성합니다. **손글씨 필기판 열기**에서 마우스·터치·펜으로 필기할 수 있습니다. 색상·굵기·지우개·한 획 취소·전체 지우기를 제공합니다.
3. 상담메모 입력란 바로 아래의 **상담메모 새로 저장** 또는 상단 **새로 저장**을 누릅니다. 직접 적거나 수정한 문장도 현재 입력값 그대로 저장합니다. **기기 저장 완료**가 표시되는지 확인하세요. 체크만 하거나 필기만 했을 때는 자동 저장하지 않습니다.
4. 입력란 아래 **저장한 메모 열기**를 누르면 **저장1, 저장2…** 선택 버튼이 표시되어 해당 메모를 바로 열 수 있습니다. 상단 **저장 목록 → 저장N → 열기**도 같은 저장본을 사용합니다. 당시 질문 틀로 체크를 복원하며 현재 개인 질문 설정을 자동 변경하지 않습니다. 다음 대상자로 전환하면 현재 개인 질문 틀로 돌아옵니다. 저장 메모의 질문 틀 편집은 제한합니다.
5. 다른 기기에서 쓰려면 해당 저장본의 **Drive에 복사**를 누릅니다. 다른 기기에서 같은 Google 계정·원래 잠금 암호로 접속한 뒤 **Drive에서 불러오기**를 누릅니다.

처음 Drive를 연결할 때는 Google로 이동하면서 현재 화면이 초기화됩니다. 작성한 내용을 먼저 기기 저장한 뒤 연결하세요. 목록 번호는 기기별로 발급하며 가져온 자료는 해당 기기의 다음 번호를 받습니다. 기기 간 같은 번호가 같은 자료를 뜻하지는 않습니다. 내부의 고유 ID로 중복과 덮어쓰기를 방지합니다.

## 저장 위치·보호

- 체크·문장·필기는 저장 버튼을 누르기 전에는 화면 메모리에만 있습니다. 저장 시 기존 AES-GCM 키로 전체를 암호화합니다. 별도의 서버·DB 서비스·분석 도구를 추가하지 않습니다.
- 이 기기 저장은 브라우저 IndexedDB의 전용 저장소 `vhm-consultations-v1`을 사용합니다. 암호문·무작위 ID·시각·번호·키의 식별값만 보관하며 내용과 잠금 암호는 평문으로 보관하지 않습니다. 암호화 키는 기존 방식대로 이 창의 메모리에만 있습니다.
- 잠금·로그아웃 때 화면의 상담 내용과 필기, 열린 저장본을 지웁니다. 필요한 내용은 먼저 저장하세요. 암호화된 저장본은 삭제하지 않습니다. 다른 창의 잠금 상태는 기존 앱과 같이 창별로 적용됩니다.
- Drive 복사는 사용자가 별도로 누를 때만 실행합니다. 기존 `drive.file` 권한을 이용해 개인 Drive의 기존 연계자료 폴더에 무작위 이름의 암호화 파일을 만듭니다. 공유 권한은 추가하지 않습니다. 기존 `vhm-links.json`, 질문 틀 파일 `vhm-notes.json`, 일정 메모는 덮어쓰지 않습니다.
- Drive 가져오기는 유효한 파일을 날짜순으로 기기에 병합합니다. 같은 ID·같은 암호문은 중복 추가하지 않으며 같은 ID의 다른 암호문은 실패로 표시하고 기존 기기 저장본을 유지합니다. 손상·암호 불일치 파일도 기존 저장본을 지우지 않습니다. Drive 복사를 동시에 실행해 같은 파일이 중복 생성되어도 가져오기에서 고유 ID로 합칩니다.
- 기기 번호는 IndexedDB 단일 트랜잭션에서 배정하므로 여러 탭에서 동시에 저장해도 중복 번호로 덮어쓰지 않습니다. 삭제한 번호는 재사용하지 않습니다.
- **이 기기에서 삭제**는 해당 기기의 저장본만 지웁니다. Drive 복사본은 남고 나중에 가져오면 다시 추가됩니다. Drive 원본 삭제가 필요하면 사용자가 Drive에서 해당 파일을 관리해야 합니다.

## 외부·오프라인 사용 시

미리 사이트를 열고 로그인·잠금 해제를 마친 화면에서는 인터넷이 끊겨도 기기 저장이 가능합니다. 완전한 오프라인 앱 설치나 처음 접속·로그인은 지원 범위에 포함하지 않습니다. 처음 로그인·암호 설정·Drive 복사/불러오기에는 인터넷 연결이 필요합니다.

기기 저장만 한 자료는 다른 기기에서 자동으로 나타나지 않습니다. 브라우저 데이터 삭제, 비공개 창 종료, 기기 분실 등으로 사라질 수 있으므로 필요한 저장본은 Drive에도 복사하세요. 기존 일정 JSON 백업에는 상담 저장본이 포함되지 않습니다. 잠금 암호를 잊으면 암호화된 상담 저장본도 복구할 수 없습니다.

저장 한 건은 암호화 전 합계 2MB, 필기 2,000획·30,000점까지입니다. Drive 불러오기는 한 번에 1,000파일까지 처리합니다. 용량 부족·저장 실패는 완료로 표시하지 않으며 현재 작성 내용과 기존 저장본을 유지합니다.

자동 검증은 가짜 Google 응답과 가상 상담문·필기만 사용합니다. 실제 개인정보나 실제 계정의 상담 자료를 테스트에 이용하지 않습니다.
